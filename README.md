# Blogs API

A powerful RESTful Blog API built with Django and Django REST Framework.  
This API provides authentication, blog management, categories, comments, likes, save-for-later functionality, and user profile features.

---

# Features

## Authentication
- User Registration
- User Login
- User Logout
- Email Update
- Password Change

## Blog Features
- Create Blog
- Update Blog
- Delete Blog
- List Blogs
- Blog Details

## Categories
- Create Category
- Update Category
- Delete Category
- List Categories

## Article & Paragraph System
- Create Articles
- Add Paragraphs
- Rich Blog Content Structure

## Social Features
- Comment on Blogs
- Like Blogs
- Save Blogs for Later

## Profile Features
- User Profile
- Update Profile
- Profile Image Upload

- Python
