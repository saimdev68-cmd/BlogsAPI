# 📝 Django Blog API (REST Framework)

A fully-featured Blog API built with **Django & Django REST Framework**, designed for real-world use cases with authentication, user interaction, and content management.

---

## 🚀 Features

### 📰 Blog System
- Category-based article organization
- Articles with structured paragraph support
- Clean and scalable content architecture

### 🔐 Authentication & Security
- Token-based authentication using Django REST Framework
- Secure login/logout system
- Permission-based access control

### ❤️ User Interaction
- Like system for articles
- Save & Bookmark functionality
- Comment system with full control

### 💬 Comment System
- Anyone can view comments
- Only authenticated users can create comments
- Users can **update & delete only their own comments**

### 👤 User Profile System
- Custom user profile model
- Username & profile picture support
- User-specific activity tracking
